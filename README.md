# Focus Base — Life Planner

A personal ADHD/OCD-friendly life planner: tasks, cleaning schedule, habit tracker, reading & movie list with reviews, self-care reminders, goals, and notes.

## Deploy

This is a single self-contained `index.html` file — no build step, no dependencies to install.

**Vercel:**
1. Push this repo to GitHub.
2. Go to https://vercel.com/new and import the repo.
3. Leave all settings as default (no framework, no build command needed) and deploy.

**Netlify Drop (no account needed):**
1. Go to https://app.netlify.com/drop
2. Drag `index.html` onto the page.
3. Get your live URL instantly.

## Using it on your phone

1. Open your deployed URL in Safari (iOS) or Chrome (Android).
2. Tap the Share button → "Add to Home Screen."
3. It'll launch full-screen like a native app.

## Data & backups

Your data saves automatically to the browser's local storage on whichever device you're using. Use the **Export backup** button in the sidebar regularly to save a `.json` copy — especially before clearing browser data, switching phones, or reinstalling. Use **Import backup** to restore it.

Note: since this uses local storage (not a database), your data does *not* sync automatically between devices. Each device/browser keeps its own copy.
